Owner Control & Safe Mode

Load state दबाएँ।

Lock/Safe Mode write operations रोकते हैं। Unlock और mode changes के लिए exact confirmation phrase और Founder permission आवश्यक है।

Technical log retention

Cleanup only targets technical/security/email/reset logs. Orders, products, coupons, purchase requests and download records are preserved.

Encrypted database backup

Backup AES-256-GCM से encrypted होगा। Cloudflare secret BACKUP_ENCRYPTION_KEY staging Worker में configure होना चाहिए। Database rows और file keys export होते हैं; R2 में रखी PDF files इस backup में शामिल नहीं हैं।

Restore to staging (merge only)

Restore केवल तब चलेगा जब Worker का APP_ENV=staging हो। यह records merge करता है, target-only records delete नहीं करता, और target sessions revoke करता है। इसे production पर deploy न करें।
